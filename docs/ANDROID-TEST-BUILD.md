# Android test APK with GitHub Actions

The workflow `.github/workflows/android-test-apk.yml` creates a debug APK that can be installed directly on an Android device. It does not use EAS Build and does not require an Android release keystore.

## GitHub configuration

Open **Settings → Secrets and variables → Actions** in the repository.

Create this repository variable:

| Variable | Value |
| --- | --- |
| `EXPO_PUBLIC_API_URL` | The API URL reachable from the test device, such as `https://api.example.com`. |

Create this repository variable (the workflow also accepts a secret with the same name):

| Variable | Value |
| --- | --- |
| `ANDROID_GOOGLE_SERVICES_JSON_BASE64` | Base64 of Firebase `google-services.json` for package `com.igen.connect`. |

Convert the Firebase file to Base64 in PowerShell:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("google-services.json")) | Set-Clipboard
```

Paste the clipboard value into `ANDROID_GOOGLE_SERVICES_JSON_BASE64`. The workflow reconstructs the file only on the temporary runner.

## Build and install

The workflow runs automatically on pushes to `main` and `feature/personal-profile-gallery-menu`. To run it manually, open **Actions → Android test APK → Run workflow**.

After it succeeds:

1. Open the workflow run.
2. Download `igen-connect-test-<run-number>` under **Artifacts**.
3. Extract the downloaded ZIP.
4. Copy `app-debug.apk` to the Android device and install it.

Android may require enabling **Install unknown apps** for the browser or file manager used to open the APK.

The APK uses Android's standard debug signing key generated by Gradle on the runner. It is intended only for internal testing and cannot be uploaded as a production release to Google Play.
